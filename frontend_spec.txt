Frontend design (Django Template + Bootstrap)

1) Dashboard page: /dashboard-page
- Input fields:
  - genealogy selector
- Display fields:
  - total members
  - male count + ratio
  - female count + ratio
- Interactions:
  - switch genealogy and refresh statistics

2) Login page: /login-page
- Input fields:
  - username
  - password
- Display fields:
  - login error message
- Interactions:
  - submit form
  - on success redirect to /members-page

3) Member management page: /members-page
- Input fields:
  - genealogy create form (title, surname)
  - genealogy selector
  - collaborator invite form (username, role; owner only)
  - name prefix search
  - create member form (name, gender, birth_year, death_year, biography)
  - inline edit form for each member (name, gender, birth_year, death_year, biography)
  - delete member action
- Display fields:
  - member list table
  - selected genealogy title/surname + current role
- Interactions:
  - create genealogy
  - invite collaborator (owner only)
  - fuzzy search with prefix (LIKE 'xxx%')
  - create member
  - update member
  - delete member
  - switch genealogy view

4) Tree display page: /tree-page
- Input fields:
  - member selector
- Display fields:
  - descendant tree rendered as nested nodes
- Interactions:
  - select root member
  - render descendants tree dynamically by JSON data

5) Ancestor tree page: /ancestors-tree-page
- Input fields:
  - member selector
- Display fields:
  - ancestor tree (father/mother branches)
- Interactions:
  - select member
  - render ancestor tree dynamically by JSON data

6) Analysis page: /analysis-page
- Input fields:
  - member selector (Q1)
  - genealogy selector (Q3/Q4/Q5)
  - two member selectors (Q6)
- Display fields:
  - raw JSON result blocks for each query
- Interactions:
  - trigger Q1 spouse+children query
  - trigger Q3 longest-lifespan-generation query
  - trigger Q4 unmarried-male-over-50 query
  - trigger Q5 early-born-members query
  - trigger Q6 relationship-sql path query
